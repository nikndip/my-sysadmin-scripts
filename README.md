## Что находится в текущей версии

Основой работ служит `script.sh`: он записывает время и результаты команд `free -h`, `df -h` и `uptime` в `monitor.log`, делая паузу 5 секунд между измерениями.

Во втором задании скрипт запускается внутри контейнера. Его журнал доступен через HTTP-сервер и Nginx с HTTPS. Отдельно выполнены упражнения по созданию и монтированию RAID1 и LVM.

| Файл или каталог | Назначение |
| --- | --- |
| `script.sh` | Скрипт мониторинга |
| `sample_output.txt` | Пример результатов работы |
| `Dockerfile` | Сборка образа |
| `docker-compose.yml` | Настройка запуска контейнера |
| `nginx/` | Конфигурация reverse proxy и HTTPS |
| `systemd/` | Служба управления контейнером |
| `HW2.md` | Подробное описание ДЗ №2 и команды развёртывания |

Инструкция по запуску текущей версии и результаты проверок приведены в [описании ДЗ №2](HW2.md).

Системный паспорт из ДЗ №1 и скриншоты выполнения передаются отдельными приложениями на учебной платформе.
