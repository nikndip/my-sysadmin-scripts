# Мониторинг ресурсов — вариант Б

Bash-скрипт каждые 5 секунд записывает временную метку и вывод free -h, df -h и uptime в monitor.log.

## Запуск

В Linux перейдите в каталог репозитория и выполните: `./script.sh`.

Необходимы Bash и команды date, free, df, uptime, sleep.
Интервал задан константой INTERVAL=5 в script.sh; интерактивный ввод не требуется.

## Результат и остановка

monitor.log создаётся в текущем каталоге. Новые блоки дописываются, предыдущие записи сохраняются.
Остановка: Ctrl+C или SIGTERM; скрипт сообщает об остановке и завершается с кодом 0.
sample_output.txt содержит три реальных блока вывода, полученных на учебной Ubuntu-машине.

## Обработка ошибок

Проверяются положительный целочисленный интервал, наличие необходимых команд и возможность открытия лога для записи.
При провале проверки выводится сообщение в stderr, скрипт завершается с кодом 1.
set -euo pipefail прекращает выполнение при других необработанных ошибках.
